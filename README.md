# Autonomous Mobile Robot Navigation using A*

## 📌 Description
This project demonstrates goal-oriented path planning using the A* algorithm in a known map.

## 🚀 Features
- A* shortest path planning
- Dynamic obstacle detection
- Real-time replanning
- Pygame visualization

## 🛠️ Technologies
- Python
- NumPy
- Pygame

## ▶️ How to Run
```bash
python main.py
